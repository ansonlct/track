數據點樣嚟？

本頁使用九巴 / 運輸署公開 ETA 資料。公開 API 提供的是「預計到站時間」，並沒有公開每架巴士的車牌、車隊編號或真實 GPS 到站 timestamp。

Collector 每分鐘保存 Route ETA snapshot，再把同一站連續出現、時間相近的 ETA 聚合成一次「推算到站事件」。相鄰站事件會按時間先後配對，用來估算站與站之間的車程。

所以：頁面的「到站時間」應理解為 ETA-based inferred arrival，而不是營運商提供的官方 actual arrival time。短至 1–2 分鐘的站距尤其可能有約 1 分鐘級誤差。

原始 snapshot 會保留在 SQLite，日後可以用更好的演算法重新計算，毋須重新收集歷史資料。
