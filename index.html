DATA METHOD

數據點樣嚟？

本頁使用九巴 / 運輸署公開 Route ETA 資料。GitHub Actions 會自動收集，不需要開住你自己任何電腦。

公開 API 提供的是「預計到站時間」，並沒有公開每架巴士的車牌、車隊編號或官方 GPS actual-arrival timestamp。因此系統會把每分鐘的 ETA snapshot 聚合成「推算到站事件」，再按相鄰站時間先後重組成班次。

時間定義：右邊顯示 ETA-based inferred arrival（以公開 ETA 推算的到站時間），並非營運商官方 actual-arrival timestamp；短站距可能有約 1 分鐘級誤差。

「最快／最慢／平均／中位數／P90」由累積到的逐站推算時間計算，數據愈多，長期比較愈有參考價值。
